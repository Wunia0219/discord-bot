# LUNA 月光遊藝室 — 內部動畫樣品

本機互動樣品，用於確認轉輪、停輪、音效、大獎與里程碑演出。尚未接入 Discord、OAuth、正式後端或公開服務。沒有真實籌碼或購買功能。

## 啟動

需要 Node.js 22.12+（本機使用 24）。

```sh
npm install
npm run dev
```

開啟 http://127.0.0.1:4187 。服務僅綁定本機，不對外公開。

```sh
npm test
npm run build
```

## 試玩

- 初始 10,000 測試籌碼，可選 50 / 100 / 250 / 500。
- 一般旋轉使用測試分布：未中獎 50%、2 倍 30%、5 倍 15%、20 倍 5%。派彩含本金。235% 理論回饋率僅方便展示，不是正式規則。
- 大獎與里程碑預覽不變更籌碼和紀錄。
- 音效預設關閉，點擊右上角音效按鈕啟用。音訊由 Web Audio 合成，無外部音檔。
- 最近 100 局和首次 12,000 里程碑保存在 localStorage；重設試玩會清除。
- 本機結果在動畫開始前保存，關閉再開可查看已保存結果。前端帳本可被使用者修改，不具有正式防作弊或跨裝置同步能力。
- 遵循 reduced-motion，分頁隱藏時停輪到結果並暫停繪製。

## 第一階段驗收邊界

可在本機檢查：動畫、指定結果停輪、連點保護、預覽不扣款、紀錄對帳、重新整理恢復、窄螢幕排版。

仍待 Discord Application 設定後驗證：Activity 啟動、SDK 身分驗證、Discord Proxy 素材/API、Discord 桌面與 iOS/Android 實機音效及效能。

動畫引擎與純資料規則分開。接入 Discord 時保留演出層，以後端回傳結果替代本機 createRound。正式版需伺服器端身分驗證、交易帳本、冪等請求與持久資料庫。

美術為程式繪製的向量符號；沒有付費或遠端素材、沒有建立雲端資源。
