# CROWNS OF KEMET 凱美特之冠 — 5×3 內部動畫樣品

以使用者提供的 RSG Crowns of Kemet 素材製作五軸三列試玩機台。尚未接入 Discord、OAuth 或正式後端。

## 啟動與檢查

Node.js 22.12+。執行 `npm install`、`npm run dev`，開啟 http://127.0.0.1:4187/ 。服務僅綁定本機。

- `npm test`：帳本、冪等、機率邊界、5×3 結果與紀錄還原。
- `npm run build`：建立靜態版本至 dist/。

## 素材與呈現

- `images/main.png` / `main.json`：機台、標誌、阿努比斯、BIG WIN 與裝飾。
- `images/symbols.png` / `symbols.json`：生命之符、荷魯斯之眼、項鍊、聖甲蟲、WILD。
- `images/background.png`：從使用者指定的素材包 PNG/background 複製，原圖保持不變。
- 沒有採用 AI 生成圖片。若缺少素材，先向使用者確認位置。
- 圖集依原始像素座標讀取，符號保留透明邊界。五軸依序減速，最後三格已插入演出序列，停輪不另行替換符號。
- 阿努比斯目前作為桌面版的機台外側裝飾，沒有實作佔滿整軸的角色符號。

## 試玩規則

初始 10,000 測試籌碼，下注 50 / 100 / 250 / 500。MAX BET 只選擇 500，不自動旋轉。

此版只有中央水平連線派彩：未中獎 50%；五個生命之符 30%、派彩 2 倍；五個荷魯斯之眼 15%、5 倍；五個 WILD 5%、20 倍。派彩含本金，235% 理論回饋率僅方便觀察演出，不是正式遊戲機率。上下列僅供展示，WILD 尚未實作替代功能。

目前仍是先選擇結果再安排動畫，沒有固定機率 reel strip。正式機率、連線、Wild/Scatter 與自動旋轉需另行設計。

大獎與里程碑預覽不改變籌碼或紀錄。音效預設關閉，使用 Web Audio 合成；系統減少動態效果時會縮短停輪並關閉粒子。切到背景分頁會結束當局演出並暫停繪製。

## 保存

最近 100 局包含完整 5×3 盤面、下注、派彩、淨損益、餘額、時間與局號。當局結果先存後播；重新整理可恢復上一局盤面與餘額。新版本使用 `kemet-slot-preview-v2` localStorage key，舊版 Luna 的本機資料不會刪除或混用。

本機帳本可被修改，尚未具備正式防作弊或跨裝置同步能力。所有籌碼純測試，不能購買、轉讓或兌現。Discord Activity 啟動、SDK、Proxy 與手機實機效能仍待後續整合驗證。
