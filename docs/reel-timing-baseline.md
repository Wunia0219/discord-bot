## 互動與結算契約

- 桌機、手機、點擊、觸控與空白鍵共用快停；不顯示快停提示文字。
- 按下 SPIN 優先送出結算請求，同步展示動畫；結果到達前只顯示持續轉動，不預先決定停點。
- 正常與快停共用轉速、逐軸停輪音、減速與回彈。第一軸已開始減速後，保留原收尾。
- 網路等待計入正常空轉；慢回應不重新播放整段長空轉。轉輪以實際 `elapsedMS` 前進，避免慢幀拖長動畫。
- 每局只結算一次；未確認請求保留原 request ID。原兩秒開轉冷卻與交易完成後的剩餘時間計算保留。
- 本局結果不等待較舊歷史分頁；已確認結算不因背景歷史同步失敗而重新下注。
- 保留同批四份文件讀取與一次原子提交、現有官方美國區域入口及原資料範圍。
- 正式遊戲不持續收集停輪耗時；測速 hooks、回報標頭、彙總、專用變數與區域探測皆已清除。
