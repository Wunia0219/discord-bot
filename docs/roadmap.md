## 1. 每局固定成本：程式、測試與資料切換完成

v2 每局文件寫入由 10 降至 6；根帳本的四個單欄位查詢鍵取代四份流水副本。錢包保留無損壓縮的最近 100 局快取，以免冷登入額外讀取 100 份文件；前端採輕量狀態、增量合併及版本缺口補齊，並加入更早紀錄的載入入口。量測、相容性及完整驗收見 [Firestore v2](firestore-v2.md)。

10/24 已取得最新完整快照、dry-run、在原額度檔下移入新的空白 v2 namespace，逐筆與 API 驗證後切換入口。全歷史與餘額一致，切換後備份及監控通過，Webhook 設定保留。剩餘為真人 Discord 電腦／手機及自然大獎驗收。

最新保護資料含使用者實測新增的 5 局，已加密還原並逐表比對；原 v1、最新設定及程式均保留，詳見 [遷移進度](firestore-v2-migration-status.md)。此入口仍依賴個人電腦；零費用雲端實作及隔離測試已完成，實際部署與異地備份驗收尚未完成；各階段必要的資料安全檢查不延後。

已有 v2 新進度時，回退需先備份新進度，再還原至新的 v1 namespace；不能切回停留在舊進度的原 namespace。此還原路徑已在模擬器驗證。後續仍應量測全域 metadata 的競爭與實際索引／網路成本，沒有實際瓶頸前維持既有編號及備份契約。

## 2. 補齊異地恢復與故障可見性

已補齊 [可攜式加密備份](portable-backup.md)：一致快照、AES-256-GCM、驗證後發布、完整解密驗帳、只還原到新檔。最新 763 局的真實快照已加密及還原，所有表與原歷史逐列一致。此功能不連雲端，尚不算異地備份完成。

下一步在指定的私密雲端位置上傳驗證完成的加密檔，下載比對並從隔離環境還原；記錄來源、雜湊、時間與保留規則。上傳失敗保留本機有效副本並告警；通知必須能去重、回報恢復，且不含玩家資料或憑證。優先監控備份過期、額度、磁碟與服務離線。

完成條件：模擬原主機不可用，在隔離環境從異地快照恢復全部餘額、帳本、回合及原請求去重；記錄可接受資料落後時間（RPO）與還原時間（RTO）。目前每天備份可能落後約 24 小時，持續失敗會更久；需由實際營運需求設定目標。確認存放位置與告警接收者後才接入外部服務。

## 3. Firestore 精彩得獎公告：已啟用，待真人驗收

設定與卡片格式共用，Firestore 派送器不依賴 SQLite 的 `prepare()`。指定群的大獎事件跟結算在同一交易保存，只存名稱、倍率、回合識別與狀態；結算不等待 Discord。普通 v2 局維持 6 次文件寫入，大獎且啟用公告時為 7 次，背景派送另計並受專案及持久子額度雙重限制。

已測試 SUPER／MEGA、10 分鐘合併、同局去重、跨群隔離、429、逾時、並行派送、重啟與含公告的備份回退。Discord 已接受但回應遺失時保留不確定狀態，不盲目重貼。專用 Webhook 已啟用；另依使用者授權發一張明確標示的測試卡片，傳輸、讀回、瀏覽器及使用者確認正常，沒有遊戲寫入。自然大獎的端到端流程仍待驗收，不要求玩家大量刷局。實測與回退見 [Discord 測試入口](discord-test-entry.md)。

## 4. 完成玩家內容與手機體驗

背景曲目確定後，接入 `MUSIC_SOURCE`，保留音效／音樂獨立開關、首次互動才播放、背景暫停及恢復規則。荷官動畫已完成接入，後續是實機驗收及載入改善，不再重建同一套動作。

完成條件：Discord 桌面與手機完成首次載入、音效切換、AUTO、背景切回、減少動態、長時間遊玩與記憶體量測。先量測 51 頁動畫圖集及現有 bundle 的下載／解碼成本，再決定預載、延後載入或尺寸分級；不為節省流量改變原人物或動作規格。

## 5. 零費用雲端運行：實作完成，等待 Free 帳戶與部署驗收

使用者沒有持續開機的電腦，並選擇先維持零費用、接受架構調整。已實作 Cloudflare Workers Free 與 SQLite-backed Durable Objects，保留 Firestore v2 玩家資料契約；免費額度不足就停止，不自動升級付費。程式、已驗證情境、帳戶設定及回退步驟見 [雲端執行手冊](cloud-runtime.md)。

已完成真正 workerd 的隔離登入、結算、去重、session 重啟、公告 alarm、固定 readTime 備份與新增進度回退。剩餘完成條件：Free 帳戶下的實際 CPU／用量、真人雙裝置、異地下載還原、指定外部告警及入口切換驗收。個人電腦關機不再影響服務後，才算這一項完成；目前沒有開通或發布外部服務。

## 每階段共用的完成標準

新舊結果可比對、失敗不部分入帳、同請求只結算一次、全歷史可恢復。記錄固定情境的讀／寫／傳輸量及玩家等待時間，維護文件入口而非新增重複待辦。未改玩法不重跑昂貴的完整數學枚舉；涉及資料格式時一定重跑模擬器的移入、備份與還原驗收。
