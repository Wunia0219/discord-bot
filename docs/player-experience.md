# 玩家體驗

## 文案與操作

- 玩家只看見自己的戲籌、簽到與遊玩紀錄；錯誤給出可採取的下一步，不顯示資料庫、SDK、憑證或內部規則代碼。
- 用「獲得戲籌」描述派彩，用「戲籌變化」描述派彩減下注；有派彩不一定獲利。管理重設顯示前後餘額，不冒充新派彩。
- 週簽到在遊戲內領取，連續七天循環、中斷重來；顯示伺服器實際獎勵及已領狀態。
- SPIN／空白鍵共用開轉與快停。已確認結算後才落地，兩秒冷卻與全部時間參數見[停輪基準](reel-timing-baseline.md)。
- 暫扣下注只是畫面預覽，不改權威餘額；原請求恢復不再暫扣，失敗回復最後確認值。
- 歷史同步在背景完成，查看紀錄時才等待；同步失敗可重試，不能造成第二次下注。
- AUTO SPIN 等待派彩與荷官演出；開視窗、切背景、餘額不足時停止。

## 顯示與無障礙

桌面等比例機台、手機直向多排控制列，Discord platform 優先於輸入裝置判斷。圖標、人物不拉伸；金色數字保留可讀文字及完整金額。

主畫面空白鍵開轉，不意外觸發先前聚焦的按鈕；Enter 保留按鈕功能。視窗開啟時不開轉，Esc／關閉按鈕離開並恢復焦點。規則分頁支援方向鍵、Home／End，紀錄可用鍵盤展開。

音效與音樂分開啟用，預設關閉；背景時暫停，恢復時只開原本啟用的聲道，不補播舊音效。減少動態效果時省略回彈及粒子，保留結果與操作回饋。

## 玩法與演出

下注額 20／100／200／500，五軸三列、243 路；從第一軸起連續至少三軸同圖標得獎，份數相乘，同圖標只付最長獎。完整賠率及數學見[規則](game-math.md)，畫面規則取自同一模型。

停輪全部結束才派彩；每局只播放最高適用得獎音。BIG／SUPER／MEGA 門檻為總下注 10／30／100 倍。荷官小獎致意及音樂規格見[素材](assets.md)。戲籌不可購買、轉讓或兌現。
