每軸總長 200，不是重複舊 20／25 格輪帶。高分合計各軸 10%～10.5%，WILD 2%～2.5%，低分合計 87.5%。v3 的高分為 30%～32%，WILD 4%～10%；新比例均降低。低分內部比例不同，尤其黑桃／紅心較常見，讓指定較低的賠率仍能達到 96%。

輪帶包含低分交錯段與少量稀有符號段；R3–R5 的 H1／WILD 有固定堆疊，R1–R2 對 WILD 間距設限，以保留自然 200 倍最高獎並避免額外派彩使上限超標。堆疊未提高整軸稀有符號占比；所有盤面仍由實際停點決定。長度本身不改 RTP，真正改變頻率的是比例與排列。

## 完整驗證


| 指標 | 精確結果 |
|---|---:|
| 理論 RTP | 24/25 = 96% |
| 有派彩率 | 52.794737% |
| 淨獲利率 | 25.452648% |
| 單局標準差／總下注 | 1.771863 |
| 自然最高派彩 | 200 倍總下注 |
| 最高獎停點之一 | 91 / 51 / 41 / 31 / 151 |

| 演出 | 派彩／總下注 | 精確盤面數 | 平均間隔 |
|---|---|---:|---:|
| BIG WIN | 20～不足 50 倍 | 19,992,296 / 320,000,000,000 | 16,006.17 回 |
| SUPER WIN | 50～不足 200 倍 | 624,504 / 320,000,000,000 | 512,406.65 回 |
| MEGA WIN | 恰好 200 倍 | 3,456 / 320,000,000,000 | 92,592,592.59 回 |

三級互斥，每次只顯示最高符合級別。平均間隔不是固定出獎週期。SUPER／MEGA 非常稀有，可用不扣籌碼的真實盤面預覽觀看。

先獨立核對全部 59,049 種單線組合，再將相同三格窗口合併並保留權重。31／36／29／32／33 種各軸窗口，共 34,176,384 組加權盤面，精確涵蓋 320,000,000,000 組原始停點，沒有省略稀有結果。每回下注 20，總下注 6,400,000,000,000、總派彩 6,144,000,000,000，比值精確為 96%。

另跑 100 萬回交叉模擬，RTP 96.346360%；此模擬不是 RTP 或最高獎證明。正式遊戲使用 crypto.randomInt，瀏覽器獨立試玩採 rejection sampling。

模型 SHA-256：`2654e769e2fc63bf9f3b45f6b5dbdce78f2b492ec86287a0353be01e103ea298`。
