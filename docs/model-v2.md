2026-10-18，版本 `kemet-20-v2`。固定 5×3 盤面、20 線、五軸獨立等機率停點；不依餘額或輸贏改權重。

| 指標 | 舊版 v1 | 新版 v2 |
|---|---:|---:|
| 理論 RTP | 96% | **96%（精確 24/25）** |
| 各軸低分圖標 | 50 / 50 / 40 / 40 / 24% | **65 / 65 / 65 / 65 / 64%** |
| ≥20 倍派彩平均間隔 | 167.21 局 | **957.63 局** |
| 有派彩機率 | 50.075% | 49.525% |

平均間隔不是固定週期。新版常見回報提高、整體波動下降，但最高可達派彩略提高；最高派彩與其發生頻率是不同指標。

低分符號計分線的 RTP 貢獻為 64.989025 個百分點，占整體回報約 67.70%。這含 WILD 補成的低分線，不等於全無 WILD 的回報。

399、301、201、89 等非整十倍率是整數方程校準到精確 96% 的結果，不會在結算後動態補差額。WILD 可替代其他符號，或按自身倍率付獎，每線只付最高者。五個 WILD 的單線派彩是總下注 100 倍，不能把 2,000 誤讀為總下注倍數。

完整輪帶順序與各軸數量見 README 與 `src/reel-strips.js`；選定的原始資料見 `model-v2-selected.json`。

## 演出分級

| 單局總派彩／總下注 | 演出 | 配色 | 精確回合數／4,000,000 |
|---|---|---|---:|
| 20～不足 50 倍 | BIG WIN | 象牙金 | 4,134 |
| 50～不足 100 倍 | SUPER WIN | 紅寶石金邊 | 23 |
| ≥100 倍 | MEGA WIN | 亮金／酒紅描邊 | 20 |

上表互斥；「≥20 倍」合計 4,177 次、「≥50 倍」合計 43 次。SUPER 本級約 173,913 局一次，MEGA 約 200,000 局一次，因此可用預覽檢查，不需等自然觸發。各級只播放最高級，不連續重複播放三次。

三個預覽都使用該等級真實可達的停點，依當前下注計分，不扣籌碼、不修改餘額、不寫入遊玩紀錄。三種 WIN 字標已併入馬戲團 main 圖集；以高度統一比例並保留小、中、大層級。規格見 [馬戲團 WIN](circus-win-polish.md)。

## 驗證與升版

- `npm run verify:math`：獨立前綴計分器核對全部 59,049 種單線符號組合，再完整枚舉 4,000,000 組盤面；同時驗證 60～70% 低分占比與 600～1,000 局尾端目標。
- 4,000,000 局各下注 20，總下注 80,000,000、派彩 76,800,000，RTP 精確 96%。
- 另以固定 seed 960020 模擬 1,000,000 局：96.028775%。模擬僅作交叉檢查。
- 舊模型保存在 `src/models/v1`，舊本機回合照原規則驗證，保留餘額與歷史；不以新規則重算舊帳。
- 伺服器保留原資料庫及操作去重結果。重送舊版本待確認回合時，回傳原派彩；前端提示已取回舊回合，不拿新版輪帶播放舊停點。
- `/healthz` 回傳目前模型版本，用於部署核對。
- `design-model.py` 以 SciPy MILP 求解整數賠率；`design-strips.js` 以固定 seed 搜尋排列，候選 214 通過完整枚舉；`apply-designed-model.js` 只在明確重新採用已驗證候選時執行。遊戲執行期間不載入最佳化工具。
