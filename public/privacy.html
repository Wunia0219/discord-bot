隱私權政策

生效及更新日期：2026 年 10 月 30 日 · 資料處理團隊：Wunia Studio

本政策說明 Wunia Studio 在提供 Discord 應用程式「🎲命運荷官」及其中的 Joker’s Circus 遊戲時，如何處理資料，以及使用者如何提出查詢、更正或刪除要求。

1. 我們處理哪些資料

  • Discord 身分與成員資料：帳號 ID、使用者名稱、顯示名稱、頭貼資訊、所在伺服器 ID、群內暱稱，以及驗證成員資格或管理操作所需的角色與權限資訊。
  • 戲籌與遊玩資料：各伺服器的戲籌餘額、遊玩時間、下注、結果、獎勵、戲籌變化、簽到紀錄，以及核對同一筆操作所需的請求與紀錄編號。
  • 管理操作資料：發放或更正戲籌的對象、操作者、原因、數量、時間及關聯紀錄。
  • 遊戲公告資料：僅在伺服器啟用公告功能時，處理玩家名稱、得獎級別、倍率、時間、回合與公告訊息編號；出入場公告另使用遊戲連線狀態、本次遊戲盈虧、總下注、總派彩及離場時戲籌餘額，以發送及避免重複公告。
  • 登入及技術資料：完成登入所需的暫時授權碼、Discord 存取權杖及遊戲工作階段資訊。提供主機或網路傳輸的服務商也可能處理請求時間、IP 位址及必要的連線診斷資訊。
  • 客服資料：你主動聯絡團隊時提供的帳號辨識資訊、問題說明及附件；請只提供處理問題所需的內容。

目前的 Discord 登入授權範圍為基本身分及本人在指定伺服器的成員資料，不包含 Email、好友名單或一般聊天訊息。應用程式不要求你的 Discord 密碼。

2. 資料用途

我們使用上述資料確認登入身分與伺服器成員資格、提供各群獨立錢包、結算遊戲、辦理簽到與管理操作、顯示歷史紀錄、避免重複入帳、處理異常與濫用，以及回應使用者要求。頭貼與名稱用於玩家介面；啟用得獎公告時，也用於該功能。

目前應用程式未配置第三方廣告或跨站追蹤工具，也不出售 Discord 帳號資料或以其進行廣告投放。

3. 哪些人或服務可能取得資料

  • 你本人：可查看自己的戲籌及遊玩紀錄。
  • 所在伺服器的授權管理員：依管理權限，可查詢本群成員的戲籌發放、更正、簽到及遊戲摘要等管理紀錄。
  • Wunia Studio 授權維運人員：為提供服務、排除故障及處理資料要求，在必要範圍內處理資料。
  • Discord：提供身分驗證、成員資格、指令及公告傳輸等功能，依 Discord 隱私權政策處理其平台資料。
  • Netlify：提供另行開放的一般瀏覽器試玩網站及政策頁的靜態託管與傳輸，可能處理 IP 位址、請求時間及連線日誌。一般瀏覽器的試玩戲籌保存在玩家裝置，不會因瀏覽網站就上傳到 Discord 錢包。服務商的資料處理說明見 Netlify 隱私權政策。
  • Google Firebase／Firestore：保存 Discord 錢包、遊玩紀錄與原請求結果；相關說明見 Google 隱私權政策。
  • Cloudflare：提供目前 Discord 遊戲網頁與後端 API 的雲端託管及傳輸，處理登入、遊戲請求與排程，並保存加密登入狀態、服務額度與排程狀態，以及加密備份。服務可能處理傳輸中的請求、IP 位址及必要的連線診斷資料，詳見 Cloudflare 隱私權政策。

目前 Discord 錢包與遊玩紀錄保存在 Google Firestore；Cloudflare 另保存受控的加密備份，團隊下載的備份與還原驗證副本保存在受控本機設備。這些資料與 Netlify 的靜態網站分開。Discord、Google、Netlify 及 Cloudflare 的網路服務可能在多個國家或地區處理連線資料；若後端託管、資料保存或分享方式有重要改變，我們會更新本政策並公告。

如依法必須提供資料，我們會依適用要求，在必要範圍內處理。

4. 伺服器遊戲公告

如果所在伺服器啟用公告，指定文字頻道會顯示玩家名稱、SUPER／MEGA 得獎級別與總獎勵倍率。啟用出入場公告時，也會顯示進入及離開遊戲的訊息；離場公告包含本次遊戲盈虧、局數、總下注、總派彩及結算時的戲籌餘額。可存取該頻道的成員都可能看到這些資料。

遊戲盈虧以服務端的派彩減下注計算，不將簽到與管理員發放視為遊戲獲利。同一玩家同時使用多個裝置會合併計算；異常斷線或裝置暫停連線時，系統可能在逾時後發布離場公告。公告的餘額是結算當時的快照，後續操作仍可能變動。

需要處理與你有關的公告時，請提供該訊息連結並聯絡團隊；服務資料庫中的資料與 Discord 已發布訊息需要分別處理。

5. 保存方式與期間

伺服器錢包、遊玩及管理紀錄保存於服務使用的資料庫。為維持跨裝置餘額、核對操作及處理問題，目前未設固定天數的自動清除機制；資料不再為服務功能所必要、停止營運，或收到有效的刪除要求時，應依適用規範處理刪除，依法必須保留者除外。

登入工作階段最長有效一小時，不寫入錢包資料庫。目前雲端後端以加密方式暫存 Discord 存取權杖及工作階段資訊，以維持服務重啟後的登入狀態，過期資料在後續登入或維護時清除。權杖及工作階段失效後，須重新登入。

團隊為恢復服務而建立的受控備份可能包含錢包與紀錄。雲端自動備份每二十四小時嘗試建立，成功後保留最近三份通過驗證的快照；失敗的候選不會取代有效備份。手動封存副本由維運人員在恢復服務及核對資料所需期間內管理。有效的刪除要求同時涵蓋團隊可控制的備份；還原備份時，也須避免重新恢復已完成刪除的資料。服務商為自身連線維運而保存的日誌，則依其政策與適用規範處理。

6. 瀏覽器儲存

一般瀏覽器試玩使用本機儲存保存該瀏覽器的試玩戲籌與紀錄，不會自動匯入 Discord 伺服器錢包。Discord 遊玩時，瀏覽器的工作階段儲存可能暫存尚待確認的下注與請求編號，避免重送時重複扣款。

你可以透過瀏覽器或裝置設定清除本機網站資料；這會影響本機試玩與暫存，但不會刪除後端保存的 Discord 錢包與紀錄。

7. 查詢、更正、刪除與撤回授權

遊戲目前未提供自助刪除入口。若要查詢、更正或要求刪除與你有關的資料，請使用下方聯絡方式，提供對應的 Discord 帳號 ID、伺服器及要求範圍。團隊可能先以必要方式核對身分，以避免他人取得或刪除你的資料。

團隊核對身分後，會依要求範圍盡速人工處理服務資料庫、受控備份及本服務發布的相關公告，並回覆處理情況；若有依法必須保留的資料，會說明保留範圍與理由。刪除錢包資料也會影響原有戲籌與歷史紀錄。請勿僅以他人的帳號 ID 提出代為刪除要求。

你也可以到 Discord「使用者設定 → 已授權的應用程式」撤銷授權。撤銷授權會限制後續存取，但不等同於刪除先前已保存的錢包與遊玩紀錄；需要刪除時，仍請向團隊提出要求。

8. 政策更新

若資料用途、對外分享方式、供應商或其他重要處理方式變更，團隊會更新本頁日期與內容，並透過遊戲或服務公告通知重要變更。請在使用服務前查看最新政策。
